# Rock Paper Scissors
A rock paper scissors browser game created with HTML, CSS, and JavaScript. Play against a computer; first to 3 points wins!
![](attachments/Website%20screenshot.png)

This was originally made for [The Odin Project](https://www.theodinproject.com/)'s Foundations course. At the end of it, I decided come back and build upon the project using everything I learned!

Before building the website, a rudimentary design was drafted using [Canva](https://www.canva.com/):
![](attachments/Original%20design.png)

The hand drawings were made by [irasutoya](https://www.irasutoya.com/). Additionally, the color scheme was generated using [Coolors](https://coolors.co/) and the sound effects were created on [Chrome Music Lab](https://musiclab.chromeexperiments.com/Song-Maker).
